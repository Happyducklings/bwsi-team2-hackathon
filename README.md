*IMPORTANT: Make sure you have installed sshpass, openssh-server, and docker on Linux. Retrieve the repository using git, and then start up the gamefinalfinal.py file to begin your adventure!*

## Download & Play the Terminal CTF Game

The terminal game is a self-contained Python program — **no extra packages to install**. You only need Python 3 (3.8 or newer).

### 1. Check that you have Python 3

```sh
python3 --version
```

If that prints something like `Python 3.x.x`, you're set. If not, install it from [python.org/downloads](https://www.python.org/downloads/) (on Windows, tick **"Add Python to PATH"** during setup).

### 2. Get the game

**Option A — Download the ZIP (easiest)**

1. Go to the [repository](https://github.com/Happyducklings/bwsi-team2-hackathon).
2. Click the green **Code ▾** button → **Download ZIP**.
3. Unzip it, then open a terminal in the unzipped folder.

**Option B — Clone with git**

```sh
git clone https://github.com/Happyducklings/bwsi-team2-hackathon.git
cd bwsi-team2-hackathon
```

### 3. Run it

From inside the game folder:

```sh
# macOS / Linux
python3 gamefinalfinal.py

# Windows
python gamefinalfinal.py
```

Play it in a real terminal window — it clears and redraws the screen, so it won't behave correctly inside some IDE output panes.

### Troubleshooting

- **`python3: command not found`** — try `python gamefinalfinal.py`, or reinstall Python and make sure it's on your PATH.
- **Screen looks garbled** — maximize the terminal window and run it directly in Terminal (macOS), a Linux shell, or Command Prompt / PowerShell (Windows).
