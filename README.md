# Hidden Wall Maze
A seemingly simple game about messing with mazes and fending against foes, but most importantly... exploring Linux systems and solving fun cybersecurity challenges!

*IMPORTANT: Make sure you have installed sshpass, openssh-server, and docker on your system. Retrieve the repository using git, and then start up the gamefinalfinal.py file to begin your adventure!*
